# Vision

## Product Idea

OrderFlow is a B2B SaaS for small and medium businesses that need to manage custom orders, track status changes, and keep customer communication organized in one place.

## Target User

- Small agencies
- Print shops
- Manufacturing workshops
- Service businesses with custom order workflows

## Main Value

- One shared workflow for orders and customers
- Tenant isolation for multi-client SaaS use
- Structured order lifecycle tracking
- Notifications and reporting without manual spreadsheets

## Core Modules

- Authentication and tenant membership
- Customers
- Orders
- Order items
- Status timeline
- Notifications
- Audit log
- Dashboard metrics

## Non-Goals for V1

- Billing and subscriptions
- Public marketplace
- Complex external ERP integrations
